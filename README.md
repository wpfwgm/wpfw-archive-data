# WPFW archive data

Listing data for the WPFW on-demand archive embed: titles, dates,
categories, audio URLs and approved descriptions. No transcripts.

index/ is a search index over the transcripts. It maps a word to the
episodes it occurs in and how often. It holds no positions and no
surrounding text, so a transcript cannot be reconstructed from it.

Generated by `tools/build-embed.js`. Do not edit by hand.
